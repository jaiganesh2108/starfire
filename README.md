# 🌟 Starfire — AI Personal Assistant  

Starfire is an **AI-powered personal assistant** built using **voice recognition** to assist with **daily activities, student self-growth, and learning**.  
It is designed to be **developer-friendly**, providing a **unique modular codebase** that allows anyone to build from scratch and extend functionalities.  

---

## ✨ Features  

Starfire comes packed with intelligent features to assist in everyday tasks:  

- 🎙 **Voice Recognition** — Interact naturally using your voice  
- 🕒 **Date & Time** — Get the current date and time instantly  
- 🧮 **Calculator** — Solve basic to advanced calculations  
- 📷 **Camera Access** — Open and capture with the system camera  
- 📝 **Notepad** — Create and manage notes easily  
- 🤖 **OpenAI Integration** — AI-powered conversations & responses  
- 📅 **Google Calendar** — Manage schedules and events  
- 📂 **Text File Access** — Open and read text files  
- 📸 **Screenshot Tool** — Capture your screen with a command  
- 🎨 **Paint** — Open MS Paint for quick sketches  
- 💻 **System Control**  
  - 🔒 Lock System  
  - ⏻ Shutdown PC  
  - 🔄 Restart PC  
  - 📂 Open/Close files  
- ⏰ **Task Reminder** — Get notified for important activities
